# Select a direction, not a mandatory template

Start from the user's supplied reference. If no direction is chosen, offer two or three suitable alternatives. Translate vague adjectives into decisions about six properties: typography, composition, image language, color/light, motion rhythm and sound.

Record what is actually visible: flat or dimensional type, density and whitespace, vectors or photographs, texture/material, holds and cuts, easing/camera, speech/music/silence. If the reference is inaccessible, do not invent this analysis. A photo collage should not become SVG coins just because the starter contains coins.

| Direction | Typical choices | Feasible route |
| --- | --- | --- |
| Minimal/editorial | Flat type, whitespace, measured movement and holds | HTML/CSS/SVG |
| Kinetic type | Word/line/block choreography, typographic hierarchy | DOM/SVG/canvas timed to voice or music |
| Vector explainer | Diagrams, original illustrations, clear cause/effect | SVG/canvas |
| Data story | Sourced values, accurate scales, clear labels | SVG/canvas/chart primitives |
| Product/UI | Actual product imagery/UI captures, controlled crops | DOM/images/footage |
| Collage | Photos/cutouts, layered compositions and editorial type | Image compositing/canvas |
| Footage/cinematic | Real shots, restrained titles, audio continuity | Deterministic media/compositor/FFmpeg |
| Original poster | Dense Persian compositions, extrusion, illustrated props | Bundled poster preset |
| Genuine 3D | Geometry, light, materials, camera and render passes | Available 3D tool; not bundled |
| Character animation | Designed characters, poses/rig, acting and optional lip sync | Suitable animation/rigging tool; not bundled |

These are direction families, not exhaustive templates or a claim all tools are installed. Hybrid or other requested styles can be described through their properties and assigned a feasible route.

The old poster's rules are optional: one accent, six weights, extrusion, a fixed scene budget, impacts, camera push and CTA do not apply globally. Flat type, many colors, stillness and silence can be correct. Scientific graphics prioritize evidence over dramatic hits.

Before full production, show opening/content/closing style frames using actual user fonts/assets. Verify the longest text. Include a brief motion description and obtain approval. Revisit only materially changed choices. Do not merely recolor the demo and call it a new style.
